# 2. Use Excalidraw as a digital whiteboard

Date: 2025-10-17

## Status

Accepted

## Context

Project white boarding and stickies are not shareable or trackable over time

## Decision

We will use [Excalidraw](https://excalidraw.com) for sharing diagrams and save relevant renderings
to the doc/diagrams/*.excalidraw for documentation purposes over time.

When collaborating with multiple devs the online multiuser feature of Excalidraw can be used but any changes should be exported and stored in the repo.

## Consequences

Leveraging Excalidraw and retaining the excalidraw output in the repo will allow for architecture/design/collaboration to be retained and update as the project progresses.
